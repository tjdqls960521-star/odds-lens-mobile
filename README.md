# ODDS LENS Mobile

국내 베트맨 공식 배당, 네 종목 과거 배당, 시간순 확률 모델을 한 화면에서 확인하는 오픈소스 모바일 웹 앱입니다. 기존 주소와 데이터 구조를 유지한 Cloudflare Worker 기반 프로젝트입니다.

## 현재 구현

- 베트맨 공개 조회 경로에서 국내 경기·배당을 서버가 직접 읽습니다. 로그인이나 해외 배당 대체값을 사용하지 않습니다.
- 야구·축구·농구·배구의 오늘·예정 경기와 과거 자료를 지원하며, 축구는 공식 경기표에 나온 모든 리그를 표시합니다.
- 현재 배당과 원본 응답은 R2에, 배당 관측·예측·결과 수정 이력은 D1 불변 원장에 보존합니다. 원본 조회가 실패하면 마지막 정상 값을 유지하고 오류와 관측 시각을 화면에 표시합니다.
- 모바일 화면에서 조회하므로 개인 PC가 꺼져 있어도 배포된 앱을 사용할 수 있습니다. 수집은 즉시 전송형 시세 피드가 아니라 공식 공개값의 주기적 조회입니다.

## 동일 배당 패턴과 예측

- **M0**는 같은 시점의 전체 배당을 역수 정규화한 시장 기준확률입니다.
- **M1**은 과거 배당과 결과를 시간순으로 분리해 학습·보정한 확률 모델입니다. 현재 공개 범위는 독립시험을 통과한 축구 최종배당 단계입니다.
- **M2**의 리그·팀·가격대 패턴 보정은 M1보다 좋아지지 않아 비활성화했습니다.
- **동일 배당 패턴** 화면은 현재 공식 배당과 과거 최종배당의 정확한 전체 조합을 비교해 종목·리그·홈팀·원정팀별 결과 수, 과거 비율, 최근 12건, 직전 결과 뒤에 나온 결과를 표시합니다. 선택 배당 하나만 같은 과거 사례는 상세에서 별도로 봅니다.
- 직전 결과를 더한 모델은 시간순 2025·2026 재현에서 기존 배당 모델보다 안정적으로 좋아지지 않았습니다. 따라서 패턴 기반 **고신뢰 선정과 이번 경기 패턴 예측확률은 보류**합니다. 검증 화면에 네 종목의 Log loss와 전체 [재현 보고서](reports/pattern-sequence-backtest.md)를 제공합니다.
- 기존 M1 상위확률 분류 API와 후향 연구 수치는 보존하지만, 배당 패턴을 의미하는 고신뢰 표시로 쓰지 않습니다. 축구 M1의 독립 검증 범위와 패턴 검증 결과는 분리해 표시합니다.

기존 `배당 1.40 이상 · 표본 3건 이상 · 과거 적중률 70% 이상` 표시는 과거 사례를 빠르게 찾는 **연구용 탐색기**로만 남아 있습니다. 동일 배당 패턴 화면은 이 조건을 사용하지 않습니다.

## 실행과 검증

```bash
npm ci
cp wrangler.local.example.jsonc wrangler.local.jsonc
# wrangler.local.jsonc에 로컬 Cloudflare D1/R2 설정을 입력한 뒤 실행
npm run migrate:local
npm test
npm run audit:data
npm run model:historical
npm run dev
```

별도 터미널에서 모바일 화면과 빌드를 확인합니다.

```bash
npm run test:mobile
npm run build
```

데이터 범위, 모델 수치, 원장 구조, 12개 인수 테스트, 재현 절차와 남은 제한은 [Odds Lens v3 구현·인수 보고서](docs/implementation-v3.md)를 참고하세요. 화면별 사용법은 [앱 README](public/odds-lens/README.md)에 정리되어 있습니다.
