# ODDS LENS — 국내 배당 예측·과거 패턴 연구실

ODDS LENS는 베트맨에 게시된 오늘·예정 경기의 국내 배당을 읽고, 과거 배당·결과로 만든 확률 모델과 과거 사례를 함께 보여주는 모바일 웹 앱입니다. 야구·축구·농구·배구를 조회할 수 있으며, 축구 일정은 베트맨 공식 경기표에 나온 모든 리그를 대상으로 합니다.

## 화면 흐름

### 오늘·예정 경기

1. 종목을 고른 뒤 날짜·리그·시장을 거릅니다.
2. 같은 실제 경기의 판매 항목은 한 카드에 묶어 시작시간 오름차순(KST)으로 봅니다.
3. 배당 하나를 누르면 그 가격의 과거 사례를, `조합 전체`를 누르면 시장·기준점·배당 순서가 모두 같은 사례를 확인합니다.
4. 상세 화면에서 시장 기준확률, 이번 경기 M1 확률, 팀·리그·종목별 과거 사례를 서로 구분해 봅니다.

발매가 끝났어도 경기 시작 전이고 마지막 공식 배당이 남아 있으면 관찰 대상으로 표시할 수 있습니다. 원본 조회 실패·오래된 배당·미발표 가격·시작한 경기는 새 예측을 만들지 않고 구체적인 보류 사유를 보여줍니다.

### 동일 배당 패턴

같은 경기의 여러 시장은 한 카드에 묶고 시작시간순(KST)으로 표시합니다. 각 시장에서는 현재 베트맨의 전체 배당 조합과 정확히 일치하는 과거 최종배당을 비교합니다.

- 같은 종목 전체, 같은 리그, 현재 홈팀이 홈이었을 때, 현재 원정팀이 원정이었을 때를 나눠 봅니다.
- 각 범위의 홈 승·무·원정 승 또는 언더·오버 **과거 결과 수와 비율**을 표시합니다. 무승부는 홈·원정 승으로 세지 않습니다.
- 최근 12건은 오래된 사례부터 최근 사례까지 색으로 보여줍니다. 가장 최근 결과와 같았던 과거 결과 뒤에 실제로 무엇이 나왔는지도 확인할 수 있습니다.
- 상세에서 전체 배당 조합과 각 선택 배당 하나만 맞춘 과거 기록을 분리해서 봅니다.

**패턴 기반 고신뢰 선정은 현재 보류**입니다. 직전 결과를 이용한 순서 모델은 네 종목의 시간순 2025·2026 재현에서 기존 배당 모델보다 안정적으로 나아지지 않았습니다. 화면의 %는 과거 비율이지 이번 경기의 예측확률이 아닙니다. 기존 M1 상위확률 후향 분류는 검증용으로 보존하되 패턴 고신뢰로 표시하지 않습니다. [검증 방법과 전체 결과](../../reports/pattern-sequence-backtest.md)를 확인할 수 있습니다.

### 과거 배당 상세

과거 분석에서는 다음 항목을 따로 봅니다.

- 같은 종목의 동일 가격·조합
- 같은 리그의 동일 가격·조합
- 현재 홈팀·원정팀이 같은 위치와 가격에서 보인 결과
- 일반·핸디캡·언더오버의 시장과 기준점
- 초기/최종 원본 열, 정확 일치 또는 허용 범위, Wilson 95% 구간, 최근 사례

무승부는 무 선택이 적중한 경우에만 승리로 셉니다. 일반 무와 핸디무를 홈·원정 승리에 포함하지 않습니다. 미확인 결과와 대상 경기 이후의 기록도 적중률에서 제외합니다.

## 1.40·70% 화면의 의미

`배당 1.40 이상 · 정산 표본 3건 이상 · 과거 적중률 70% 이상` 표시는 과거 원본에서 눈에 띄는 사례를 빠르게 찾는 **역사적 탐색 조건**입니다. 오늘 화면의 참고 패턴과 패턴 데이터센터에서만 사용합니다.

이 탐색 결과는:

- 이번 경기의 M1 예측확률이 아니며,
- 동일 배당 패턴의 선정 조건이 아니고,
- 3~5건 전승을 100% 예측으로 바꾸지 않습니다.

탐색 조건에 맞지 않는 반대 근거와 실패 사례도 상세 화면에서 확인할 수 있습니다.

## 데이터센터

패턴 데이터센터는 네 종목의 과거 배당을 다음 관점으로 조회합니다.

- 동일 2방향 조합
- 시장 배당 하나
- 팀별 배당 하나
- 언더오버 기준값·배당
- 팀별 언더오버

가격 구간, 시장, 기준점, 팀, 리그와 시간 순서를 분리해 보여주며 과거 적중률과 이번 경기 모델 확률을 같은 값으로 취급하지 않습니다. 원본의 `초기`·`최종`은 제공된 열 이름입니다. 실제 관측 시각이나 판매 마감 직전 값으로 추정하지 않습니다.

## 데이터 원천과 보존

- **현재 국내 배당:** 베트맨 공개 조회의 경기 목록·일정·경기 상세 응답을 서버에서 직접 읽습니다. 로그인이나 해외 배당 대체 경로를 사용하지 않습니다.
- **과거 배당:** 사용자가 제공한 네 종목 Google Sheets 원본과 기존 저장 자료를 종목별로 병합합니다.
- **관측 시각:** `observedAt`은 앱 서버가 응답을 읽은 시각입니다. 베트맨이 배당을 바꾼 시각은 원천에서 제공하지 않으므로 `null`로 남깁니다.
- **원장:** 원본 응답, 배당 스냅샷, 예측 당시 입력, 보류 판단, 결과 수정본과 평가 버전을 보존합니다. 틀린 예측·취소·무효·구버전을 삭제하지 않습니다.
- **오류 처리:** 공식 조회가 실패하거나 빈 경기표가 오면 마지막으로 확인한 국내 공식값을 유지하고 오류를 표시합니다. 새 예측은 최신성·저장 조건을 만족할 때만 공개합니다.

수집과 계산은 배포된 클라우드 앱에서 실행되므로 개인 PC가 꺼져 있어도 모바일에서 접속해 조회할 수 있습니다. 공식 원천은 즉시 전송형 시세 피드가 아니며, 앱은 관측한 시각과 현재 상태를 화면에 표시합니다.

## 검증 탭

검증 화면은 다음을 분리해 보여줍니다.

- M0 대비 M1/M2의 Log loss와 Brier score
- 확률구간별 예측확률과 실제 적중률
- 모델의 2026 시간순 독립시험
- 기존 M1 상위확률 정책의 2025 경계와 2026 후향 재현
- 동일 배당의 직전 결과를 더한 모델의 2025·2026 재현 성능
- 관측·예측·보류·결과 수정 원장

모델과 분류 정책은 데이터·분할·설정·가중치·경계의 내용 해시로 버전을 구분합니다.

## 로컬 실행과 확인

프로젝트 루트에서 실행합니다.

```bash
npm ci
npm run migrate:local
npm test
npm run audit:data
npm run model:historical
npm run dev
```

브라우저에서 `http://127.0.0.1:61872/odds-lens/`를 엽니다. 모바일 화면과 배포용 산출물은 다음 명령으로 확인합니다.

```bash
npm run test:mobile
npm run build
```

데이터 감사 수치, 학습·보정·시험 구간, 모델 버전, 원장 스키마, 12개 인수 테스트와 남은 제한은 [Odds Lens v3 구현·인수 보고서](../../docs/implementation-v3.md)에 있습니다.
